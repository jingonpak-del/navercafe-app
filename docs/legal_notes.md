# 라이선스 및 운영 주의사항

## 공개 코드 라이선스

조사한 공개 GitHub 저장소 중 대부분은 명시 라이선스가 없었습니다. 명시 라이선스가 없는 코드는 공개되어 있어도 복제/재배포/수정 사용 권한이 자동 부여되지 않습니다. 따라서 이 저장소에는 해당 코드를 그대로 복사하지 않고, 기능 요구사항과 구조 패턴만 참고해 새 모듈로 재구현했습니다.

MIT 라이선스가 확인된 `GBS-Skile/NaverCafeAttendanceCrawler`도 현재는 직접 소스 복사 없이 날짜/출석 판정 아이디어만 독립 구현했습니다.

## 네이버 카페 운영 주의

- 카페 약관, 네이버 이용약관, 개인정보보호법을 준수해야 합니다.
- 회원 ID, 댓글, 활동일 등은 개인정보 또는 준개인정보가 될 수 있으므로 목적/보관기간/접근권한을 제한하세요.
- 관리자 기능(회원 등급 변경, 대량 조작)은 `dry-run`, 변경 전/후 로그, 최종 확인 절차 없이는 자동 실행하지 않는 것이 안전합니다.
- 과도한 요청은 계정/카페/서비스에 불이익을 줄 수 있으므로 rate limit과 재시도 정책을 추가하세요.
